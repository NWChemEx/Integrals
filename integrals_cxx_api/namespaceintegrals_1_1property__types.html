UQKind integrals::property_types::uq_kind_from_string ( const std::string &  uq_type)
inline

Parses a "UQ Type" module-input string into a UQKind.

This is the single place the accepted "UQ Type" string literals are spelled out; UQInitializer and UQAtomSymmBlockedDriver's tests both rely on this mapping staying in sync with UQFactory's construction logic.

Exceptions
std::runtime_errorif uq_type does not match a known UQ kind.
