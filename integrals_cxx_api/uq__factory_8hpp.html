Constructs a TaylorModel scalar spanning [center - radius, center + radius] with a maximum order of order.

When Sigma is disabled tensorwrapper::types::taylor_model_type<T> is just T, which has no order to set, so we defer to TensorWrapper's generic construction (which simply returns a scalar carrying no uncertainty). The dispatch lives in a function template because a discarded if constexpr branch is only left uninstantiated inside a template.
