integrals::DECLARE_PLUGIN ( Integrals  )

The Integrals plugin.

Load it into a ModuleManager with mm.load_plugin<integrals::Integrals>() (mm.load_plugin(integrals.Integrals()) from Python). The plugin's name is "integrals". All of the plugin's default submodules are provided by the plugin itself, so it does not need other plugins to be loaded.
